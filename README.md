# tamagotchi_bug_hunters
Grupo: Bug Hunters
Projeto de conceitos de Algoritmos: Criação de um pet virtual Tamagotchi.

Alunas: Franciele Vitória Souza, Isabelle Freitas Barbosa, Maria Eduarda Cristina Silva.

Planejamento do projeto foi feito através de videochamadas para definir funções do código e o que poderia ser implementado.
Foi definido que o pet seria algum tipo de inseto, chamando a espécie dele de Bug.
